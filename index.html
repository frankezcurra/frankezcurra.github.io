Mis Proyectos

Sistema de Garaje para el Arzobispado de Ayacucho

Sistema de gestión de estacionamiento desarrollado en Python para el Arzobispado de Ayacucho. Controla el ingreso y retiro de carros y motos, calcula tarifas automáticamente, administra abonados mensuales, y genera tickets de pago en PDF con formato de impresión térmica. Cuenta con login de operadores, base de datos SQLite, reportes y una interfaz gráfica moderna en modo oscuro.

Python Tkinter SQLite ReportLab

HTML CSS JavaScript

Sistema de Préstamos para la cooperativa Allus Peru

Desarrollo de una aplicación web para la administración y control de préstamos para la cooperativa Allus Peru, construida durante el año 2024. El sistema fue desarrollado utilizando el framework Laravel para el backend, garantizando seguridad y escalabilidad, y Tailwind CSS para una interfaz de usuario moderna, responsiva y personalizada. El proyecto incluye gestión de usuarios, control de registros y una arquitectura MVC optimizada.

Laravel PHP Tailwind CSS MySQL MVC
